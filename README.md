# Heartbeat Button Animation

A Swift implementation of an animated circular button with heartbeat visual effects. This project demonstrates a polished UI component suitable for recording or action-triggering interfaces.

## Overview

**HeartbeatButtonAnimation** is a focused iOS component library that showcases the implementation of a custom animated button with a pulsating heartbeat effect. The component is designed to provide clear visual feedback to users and enhance the user experience in applications requiring prominent action buttons, such as recording interfaces.

## Features

- **Custom Animation**: Smooth heartbeat pulsation animation
- **Circular Button Design**: Clean, circular button interface
- **Visual Feedback**: Responsive animation that draws user attention
- **Lightweight Implementation**: Minimal dependencies for easy integration
- **Swift-based**: Implemented entirely in Swift for modern iOS development

## Use Cases

- **Recording Interfaces**: Ideal for floating action buttons in recording applications
- **Call Controls**: Suitable for VoIP and calling applications
- **Interactive Elements**: Can be adapted for any application requiring prominent action buttons
- **User Engagement**: Helps highlight important user actions through animation

## Architecture

This project contains a self-contained Swift implementation of the heartbeat button component, designed for easy extraction and integration into larger iOS projects.

## Getting Started

### Prerequisites

- iOS 11.0 or later
- Xcode 12.0 or later
- Swift 5.0 or later

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/Khaled-Elsayed-Mohamed/HeartbeatButtonAnimation.git
   ```

2. Open the project in Xcode:
   ```bash
   cd HeartbeatButtonAnimation
   open HeartbeatButtonAnimation.xcodeproj
   ```

## Usage

The heartbeat button component can be integrated into your iOS application by copying the relevant source files into your project.
